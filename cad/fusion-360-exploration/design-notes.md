# Fusion 360 Design Exploration — NOT the final chassis

This folder contains the original two-tier chassis design worked through in
Fusion 360, including parametric width/length calculations driven by
component footprints (motor driver, battery, breadboard, Arduino, etc.).

**This design was not used for the final build.** The robot was ultimately
built from a single sheet of 9mm plywood, cut to size, with no walls or
two-tier structure. The dimensions and parameters in this file (3mm wall
thickness, 84x167mm footprint, 20mm tier height) do not correspond to
anything in the physical robot.

It's kept here as a record of the design process -- working through
component layout, tolerance reasoning, and parametric CAD fundamentals --
rather than as a build reference. See the main build log
(../../docs/build-log.md) for why the design diverged from the plan.

If you're replicating this build, use the plywood dimensions noted in
the build log instead, not this file.

Add chassis-concept.f3d here if you want to keep the actual Fusion
source file alongside these notes.
